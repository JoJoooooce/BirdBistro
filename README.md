# 小鸟食堂（BirdBistro）技术支持

欢迎来到小鸟食堂。本页面提供游戏玩法、App 内购买、订阅与常见问题的支持信息。

> **需要帮助？** 请在本仓库的 [GitHub Issues](https://github.com/JoJoooooce/ReleaseStoreKitDemo/issues) 中提交问题。请勿在公开内容中提供 Apple ID、支付信息、完整交易凭证、完整收据或其他个人信息。

## 游戏玩法

小鸟食堂是一款轻松的小鸟互动陪伴游戏。打开 App 后无需注册或登录，即可体验核心玩法：

- 在 **赛季** 页面每日签到，领取免费饲料；
- 在 **小鸟** 页面喂食或抚摸小鸟，观察饱食度与心情的变化，并获得互动反馈；
- 在 **商店** 页面购买饲料包，用于喂食小鸟；
- 在 **会员** 页面查看和使用已获得的背景、装扮及订阅权益。

首次使用时，完成一次每日签到即可获得免费饲料并体验喂食功能，无需购买即可使用核心互动功能。

## App 内购买与权益

App 内购买由 Apple App Store 处理。实际价格、付款方式和适用税费均以 App Store 的购买页面显示为准。

| 项目 | 类型 | 用途 |
| --- | --- | --- |
| 小包饲料 / 大包饲料 | 消耗型项目 | 获得用于喂食小鸟的饲料；可重复购买。 |
| 终身会员 | 非消耗型项目 | 永久解锁专属小鸟背景。 |
| 赛季通行证 | 非续期订阅 | 在有效期内提供赛季等级奖励与赛季限定互动反馈。 |
| VIP 月卡 | 自动续期订阅 | 在订阅有效期内解锁 VIP 小鸟装扮。 |
| SVIP 月卡 | 自动续期订阅 | 在订阅有效期内解锁 SVIP 小鸟装扮。 |

### 恢复购买

如果已购项目没有显示，请打开 App 的 **会员** 页面并选择 **恢复购买**。恢复完成后，请保持网络连接片刻，以便 App 验证和同步已购权益。

### 管理或取消订阅

自动续期订阅由 Apple 管理。请在 App 的 **会员** 页面选择 **管理订阅**，通过系统订阅管理页面查看、变更或取消订阅。取消后，订阅权益通常会持续至当前已付费周期结束。

### 退款

退款由 Apple 按其规则处理。在 iOS 设备上，可在 App 的 **会员** > **购买记录** 中选择可退款的交易并发起 Apple 系统退款申请。退款是否获批及处理进度由 Apple 决定。

## 网络与数据说明

- App 需要网络连接，以验证 App 内购买、同步已购饲料及会员权益。
- App 不要求创建账户，也不会读取或保存你的 Apple ID。
- 免费饲料、小鸟的饱食度与心情、签到和赛季进度、装扮选择等游戏进度保存在当前设备上；卸载 App、清除本地数据或更换设备后，这些本地进度可能无法恢复。
- 通过 App Store 购买的饲料和会员权益会在联网后进行验证与同步。

## 常见问题

### 无法领取签到奖励

每日仅可签到一次。请确认当天尚未完成签到，并检查设备日期、时间和时区设置是否正确。

### 购买完成后没有获得饲料或权益

请先确认网络连接正常，然后在 **会员** 页面选择 **恢复购买**。若问题仍然存在，请通过 GitHub Issues 提交反馈，并说明：

- App 版本；
- iPhone/iPad 机型与 iOS 版本；
- 问题发生的大致时间和操作步骤；
- 不包含个人信息的截图或错误提示。

请勿公开发布 Apple ID、付款信息、完整交易凭证、完整收据或完整交易编号。

### 小鸟装扮或背景无法使用

请在 **会员** 页面确认对应权益是否有效：

- 终身会员可使用专属背景；
- VIP 月卡可使用 VIP 小鸟装扮；
- SVIP 月卡可使用 SVIP 小鸟装扮。

若订阅已到期，对应装扮将暂时不可用；恢复有效订阅后，可再次选择使用。

### 为什么换设备后部分游戏进度不见了？

免费饲料、签到、赛季等级和小鸟状态属于本机游戏进度，不会跨设备同步。已购买的饲料与会员权益则可在网络可用时通过 **恢复购买** 进行验证和同步。
